# V0.1 Acceptance Criteria

V0.1 is complete when all of the following are demonstrated on staging:

- [ ] User can sign in.
- [ ] User can create/open a project.
- [ ] User can connect a GitHub repository.
- [ ] Repository file tree is visible.
- [ ] Aquila can read/search repository content through controlled tools.
- [ ] Plan mode can produce a change plan without modifying files.
- [ ] Build mode can apply multi-file changes inside an isolated workspace.
- [ ] Terminal commands execute only inside the workspace.
- [ ] Tests/build commands can be run and their outputs captured.
- [ ] Application preview can be started and viewed.
- [ ] Git diff is shown before commit.
- [ ] User can approve a commit/push workflow.
- [ ] Audit log records agent tool calls.
- [ ] UI is reviewed at 360, 430, 768, 1280, 1440 and 1920 px.
- [ ] `/health` reports ready/healthy.

## Explicitly not V0.1

- Production deployment.
- Autonomous destructive commands.
- Fine-tuning.
- Self-hosted foundation model.
- Multi-tenant billing.
